개발 중 · 시제품 단계

붙이고 확인하는 과정은 간단하게 설계하고 있습니다. 아래는 센서 부착부터 앱 확인까지 계획된 사용 흐름입니다.

  1. 배관 확인

    사용 중인 정수기 배관에 센서를 붙일 위치를 확인합니다.

  2. 센서 부착

    배관을 자르지 않고 기존 배관 겉에 센서를 붙입니다.

  3. 앱 연결

    센서가 확인한 쓴 물의 양을 앱에서 확인합니다.

  4. 교체 시점 확인

    필터 교체가 필요한 시점을 보고 다음 관리를 결정합니다.

날짜 대신 쓴 물의 양을 확인합니다

필터 교체일만 정해 두면 실제로 얼마나 썼는지 알기 어렵습니다. 센플로는 쓴 물의 양을 기준으로 교체 시점을 확인하게 합니다.

기존 정수기를 그대로 사용합니다

새 정수기로 바꾸지 않아도 됩니다. 쓰던 정수기 배관을 자르지 않고 겉에 센서를 붙여 사용량을 확인합니다.

렌탈이 끝난 뒤에도 관리합니다

렌탈이 끝났거나 직접 필터를 사서 교체하는 경우에도, 사용량을 보고 교체 시점을 판단할 수 있습니다.

가정과 사무실에서 확인합니다

일반 가정과 사무실에서 쓴 물의 양을 확인합니다. 필터를 일찍 버리거나 늦게 교체하는 일을 줄입니다.
